# Steering node library

Code specific to the steering angle node.

## Planned modules

- `as5600_reader.h` / `as5600_reader.cpp` - AS5600 magnetic encoder initialisation and angle reading
- `centre_calibration.h` / `centre_calibration.cpp` - store and apply steering centre offset
- `angle_smoother.h` / `angle_smoother.cpp` - light filtering for jitter reduction
